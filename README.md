# Google Homepage Clone

A fully responsive, modernized clone of the classic Google landing page built from scratch using HTML and CSS Flexbox.


## 🛠️ Features
- **Responsive Layout:** Rebuilt using CSS Flexbox to ensure it looks great on desktops, tablets, and mobile devices.
- **Modern Typography:** Styled with clean font scaling and hover effects matching the official Google interface.
- **Accurate Branding:** Implemented custom CSS coloring for individual characters in the Google logo header.

## 🧰 Tech Stack
- HTML5
- CSS3 (Flexbox & Responsive design properties)
